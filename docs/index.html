Fundamentos JavaScript

Exemplos e exercícios do repositório Fundamentos-JS, organizados por temas para facilitar o estudo da linguagem. Os arquivos são executados diretamente com Node.js e não dependem de uma aplicação web.

Antes de começar

  1. Clone o repositório. Copie tudo para o seu computador com: 
    git clone https://github.com/Roger-Kk/Fundamentos-JS.git
cd Fundamentos-JS
    Sem Git instalado? Use o botão verde Code → Download ZIP no GitHub e descompacte.
  2. Tenha o Node.js instalado. Para conferir: 
    node -v
npm -v
    Se aparecerem as versões, está pronto.
  3. Abra a pasta no VS Code. Depois de clonar, abra a pasta Fundamentos-JS no Visual Studio Code.
  4. Execute os arquivos pelo terminal. Use node seguido do nome do arquivo: 
    node 01_variaveis.js
  5. Instale as dependências para o desafio 7daysOfCode.js: 
    npm install

Como executar qualquer exercício

Execução pelo terminal

roda com Node

Todos os exercícios principais podem ser executados individualmente. Basta abrir o terminal na pasta do projeto: 

node nome-do-arquivo.js

Exemplo:

node 03_reduce.js
Os exemplos deste repositório foram organizados para estudo dos fundamentos de JavaScript. A execução acontece localmente com Node.js; não é necessário servidor web ou hospedagem.
