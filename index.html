Ver no GitHub Como começar

Antes de começar

01

Clone o projeto

git clone https://github.com/Roger-Kk/Fundamentos-JS.git
02

Abra no VS Code

Abra a pasta do projeto no Visual Studio Code.

03

Tenha o Node.js

Confira com node -v e npm -v.

04

Execute os exemplos

Use node nomeDoArquivo.js no terminal.
